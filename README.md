## 📌 Project Overview

This project presents the development of a **digital marketing strategy for an online senior hoodies business**.

The project covers different stages of building and promoting the business online, including branding, social media planning, content creation, campaign scheduling, and performance measurement.

Visual content created using **Blender** was also incorporated into the marketing work.
